# Code of Conduct

Riverside Books is a public repository. Be respectful in issues, pull requests, and any other space where the project is discussed. Harassment, discrimination, and abusive behavior are not tolerated in any form.

## Reporting

To report a concern about behavior in this repository, contact the maintainer at [@rhaeyyan](https://github.com/rhaeyyan), or open a [private security advisory](https://github.com/rhaeyyan/riverside-books/security/advisories/new) if you would prefer the report not be public.
