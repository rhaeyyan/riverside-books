# Product A app — Customer Ordering & Loyalty App

The Product A app for Riverside Books: search a title, see an honest stock status, reserve a
copy for pickup, and collect stamps toward a reward. See [`../product-a/`](../product-a/) for
the strategy, tech stack, and phased implementation plan this app builds against.

## Current state

Phase 0 walking skeleton — scaffolding only. The catalog page is not yet wired to the shared
Supabase project; the featured title is a placeholder. See
[`../product-a/implementation_plan.md`](../product-a/implementation_plan.md#phase-0-walking-skeleton-deployed)
for the exit condition this app hasn't met yet.
